# SQL Basics Project

## Project Overview

This project demonstrates fundamental SQL concepts using PostgreSQL. It was created to build a strong foundation in database operations and basic data analysis.

The project covers table creation, data insertion, data retrieval, filtering, sorting, and basic SQL operations.

## Objective

The main objectives of this project are:

* Create and manage a database table
* Insert records into a table
* Retrieve data using SQL queries
* Filter records based on conditions
* Sort query results
* Practice basic SQL operations
* Build a foundation for more advanced SQL analysis

## Tools & Technologies

* **SQL**
* **PostgreSQL**
* **pgAdmin**

## SQL Concepts Practiced

### 1. Table Creation

Created the required table and defined its columns and data types.

Concepts practiced:

* `CREATE TABLE`
* Primary key
* Data types
* Column definitions

### 2. Data Insertion

Added records to the table using SQL.

Concepts practiced:

* `INSERT INTO`
* Multiple-row insertion
* Working with different data types

### 3. Basic Queries

Retrieved and analyzed data using SQL queries.

Concepts practiced:

* `SELECT`
* `WHERE`
* `DISTINCT`
* `ORDER BY`
* Comparison operators
* Logical operators
* Filtering and sorting

## How to Run the Project

1. Open PostgreSQL using pgAdmin.
2. Create or select the required database.
3. Run `01_create_table.sql`.
4. Run `02_insert_data.sql`.
5. Run `03_queries.sql`.
6. Review the query results in pgAdmin.
